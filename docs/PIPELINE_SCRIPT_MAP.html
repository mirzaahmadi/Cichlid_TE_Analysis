2
te_flanking_analysis.R
folder 6/insights  (latest: V3)
Run 4× — once per species. Extends each ortholog ±10 kb, intersects with RepeatMasker TEs, writes a per-species output folder.
Inputs (per species)
OUTPUT_TABLE_orthogroup_gene_info.tsv TE_<species>_genome.fa.out GENE_<species>.annotation.gff3
→
Writes — one folder per species (×4)
<Species>_intersection_outputs/ ├─ master_table.tsv handoff ├─ density_profile.tsv handoff ├─ density_tier_summary.tsv ├─ genome_wide_composition.tsv ├─ discarded_TE_orthologs.tsv ├─ null_random_genes.tsv ├─ null_random_chunks.tsv └─ plots/ ├─ composition/ pct_te_vs_nonTE · te_class_proportions │ top20_orthologs_by_te · genome_vs_flank_breakdown ├─ density/ te_density_per_gene_lines.pdf └─ summary/ flank_completeness.pdf
The 4 species folders: Metriaclima_zebra_AF, Pundamilia_nyererei_AF, Oreochromis_niloticus_AF, Neolamprologus_brichardi_AF — each identical in structure.
